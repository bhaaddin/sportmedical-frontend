## Fixes Applied

### 1. Measurements Page (Runtime Crash)
**File:** `src/pages/Measurements.tsx`

| Bug | Before | After |
|-----|--------|-------|
| Wrong field for readings | `m.data` (undefined) | `m.readings` (correct API field) |
| Missing patient name | `m.patientName` (doesn't exist) | Lookup via `patientsApi` by `m.patientId` |
| Wrong date field | `m.sessionDate` (doesn't exist) | `m.takenAtUtc` (correct API field) |
| Detail dialog used wrong fields | `Object.entries(m.data)` | `m.readings.map(r => ...)` |

Added helper function `getPatientName()` to resolve patient names from IDs using the patients list.

### 2. Staff Page (Empty List)
**File:** `src/pages/Staff.tsx`

| Bug | Before | After |
|-----|--------|-------|
| API result never stored | `staffApi.getAll().catch(...)` | `staffApi.getAll().then(setStaff).catch(...)` |

The `useEffect` called the API but discarded the result, so the staff list was always empty.

### 3. Posudek Page (Form Does Nothing)
**File:** `src/pages/Posudek.tsx`

| Bug | Before | After |
|-----|--------|-------|
| "Generovat PDF" button | Just showed toast: `toast.success('Posudek vygenerován')` | Calls `posudekApi.create(...)` with all form fields, then shows toast |

Connected the entire form to the `POST /api/posudek` backend endpoint.
