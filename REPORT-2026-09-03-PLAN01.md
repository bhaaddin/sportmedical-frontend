### 4. `sportmedical-frontend/src/pages/Calendar.tsx`
**Added keyboard navigation and print** functionality.

**New Features:**
- **Keyboard Navigation:**
  - Arrow keys: move cell selection
  - Enter: create appointment at selected cell
  - Delete/Backspace: cancel appointment in selected cell
  - Escape: deselect cell
  - Ctrl+P: print calendar

- **Print Functionality:**
  - Opens print preview in new window
  - Formatted table with appointment details
  - Includes date range in title

- **Visual Feedback:**
  - Selected cell highlighted with teal border
  - Click to select any cell

**Impact:** Power users can navigate calendar without mouse, and print for offline reference.
