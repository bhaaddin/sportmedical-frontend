# myofullbody.glb

Bone meshes of the MyoSim full-body musculoskeletal model (MyoSuite / MyoHub `myo_sim`, Apache License 2.0,
https://github.com/MyoHub/myo_sim), merged per bone and decimated (330k -> 105k faces) by
`scripts/make_fixtures.py` (`smmove.anatomy.export.export_meshes`). Node names = MyoSim body names.
